# v1.0.3 深度研究采用可审计承保与条件式交易方案

v1.0.3 保留“深度研究”和 `deep-equity-research` 标识，但替换 v1.0.2 的通用深研边界：深度研究交付九章承保/财报分析、可复算估值、财报质量 A–D、跨市场证据和技术证据交集。交易方案只允许多头、持仓无关的条件式表达，默认 1–6 个月波段，不连接账户、券商或订单。

## Considered Options

- 继续禁止交易方案：边界简单，但无法承接用户已确认的研究到方案工作流。
- 在深度研究内部增加大量讨论、持仓和交易状态字段：能覆盖更多场景，却使主 skill 变重、路由复杂且难以审计。
- 保留深度研究为承保生产者，通过稳定 artifact 输出条件式方案，并将后续讨论解耦到独立 skill：既满足买方流程，也保持单次深研的边界和可测试性。

## Consequences

研究必须产生 `underwriting.md`、`underwriting-inputs.json`、`valuation.json`、`technical-evidence.json` 和 `trade-plan.json`；`underwriting.html` 仅是按需阅读视图，`trade-plan.html` 只有技术质量门通过且价值/技术区间有交集时生成。估值统一由 `scripts/dcf.py` 运行，缺失或不适用字段显式记录。财报质量 C/D 直接否决多头入场方案，不自动转换为做空。十六类行业以注册表和规则包实现，跨市场由显式 provider 适配器与来源账本约束。

`issuer_id`、`listing_id`、`case_id` 和版本字段成为 artifact 之间的连接键；裸 ticker 不能作为唯一主键。任何扩大到空头、账户仓位或自动执行的提案必须另行决策。
