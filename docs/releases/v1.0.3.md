# Mars Research Assistant v1.0.3

v1.0.3 将深度研究升级为可审计、可复算、可形成仅多头条件式交易方案的完整流程，新增独立的
投研分析 Skill，并把 Drive 写入重设计为跨设备投研工作台。

## 新增与改进

### 市场范围偏好

- 首次使用时强制多选市场范围：美股、港股、A 股、A/H 对比；未配置前不默认任何市场。
- 偏好保存在每台设备工作区的 `mars-market-preferences.json`；选择 A/H 对比自动包含港股与
  A 股基础范围，配对时披露汇率、权利换算、流动性、交易日差异与溢价/折价。
- 明确交易所后缀优先解析；裸代码按规则归类；裸字母 token（如 LITE）一律视为 ticker 候选，
  仅当美股是唯一已启用基础范围时解析为美股，否则要求用户选择市场/交易所，不做本地猜测。
- 标的不属于已启用市场时，提供“仅本次使用 / 加入我的市场范围”两个明确选项，不静默扩权。

### 深度研究（`deep-equity-research`）

- 固定九章承保报告，支持首次承保与财报更新两种模式；财报更新无旧模型时自动降级为首次承保
  并明示。
- 财报质量 A–D 评级（应计、Beneish、收入确认红旗、现金流、审计治理五个组件，规则版本化）；
  C/D 级确定性否决多头入场方案，任何情况下不输出做空建议。
- 可复算估值引擎：三情景 DCF（保留为可审计 baseline）、通用驱动型 DCF（经营驱动逐年推导
  现金流，带 usable/conditional/unreliable 质量门槛）、反向 DCF、PVGO、PE、EPV、EVA、
  SOTP 与定 seed 蒙特卡洛；缺输入即记缺口，不伪造数字。
- 十六类行业注册表与 US/HK/A 股/A-H/VIE/ADR 市场合同；行情经显式 provider 适配器获取并
  记入来源账本，不静默 fallback。
- 决策门全部通过时交付仅多头、持仓无关的条件式交易方案（默认 1–6 个月波段）：入场区间、
  目标区间、失效条件与注释图 `trade-plan.html`；任一决策门不通过只给观察/等待条件。
- 研究报告可按需生成单文件 `underwriting.html` 阅读视图，数值与 Markdown 源稿一致。

### 投研分析（`investment-analysis`，新增）

- 只处理用户明确指定的本地 artifact、Drive 文档或 `case_id`，默认输出增量讨论卡
  （Markdown + JSON）：新证据、假设变化、论点状态、方案 revision。
- 不广泛搜索、不重跑深度研究、不自动调用其他 Skill；升级仅以文字提议。

### Drive 写入（重设计为投研工作台）

- 只公开两类能力：初始化投研工作台，以及写入交易想法、已确定方案、决策变更与复盘。
- 一个标的/案例一个主文档，固定四区：想法日志、当前方案、决策变更、复盘；完整研报只以
  artifact ID/链接引用，不复制专题研究正文。
- 方案使用稳定 `plan_id` 与递增 `revision`；父版本冲突显式化并要求用户选择；Drive 不可用
  时写入可见本地 outbox，不后台上传。
- 初始化与写入分别提议、分别确认，互不授权；写入后按 ID 读回核验。

## 明确边界

- 不读取账户、持仓或订单，不做空，不输出仓位比例，不执行交易。
- 研究结论为可审计材料，不使用交易指令词；所有来源保留带时区的 `as_of`。
- 技术面分析的内置行情源为 yfinance（非官方、best-effort），是唯一需要第三方 Python 依赖
  的子 Skill，首次调用时才按锁文件准备独立环境。
- 本地交付写入活动工作目录的 `mars-research/`，唯一命名、绝不覆盖。

## 性能与验证

- 运行包：50 个文件、778,958 bytes，低于 80 文件和 1.5 MiB 的新基线。
- 个股快览与深度研究承保 fixture 渲染均低于 1 秒（实测约 0.04 秒）。
- 发布前完成八个 Skill 合同、运行包边界、市场偏好解析、估值/财报质量/交易方案引擎、
  承保渲染与 Drive 工作台本地模拟的完整离线验证。

## 升级提示

重新执行 `npx skills add archerthegoat/mars-research-assistant --skill mars-research-assistant
--agent codex --global --copy` 即可安装 v1.0.3。首次单标的研究前会要求多选市场范围；偏好
按设备保存，只有明确要求时才随 Drive 同步。
