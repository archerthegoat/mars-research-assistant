# Mars Skills 路线图

## v1.0.2（已发布）轻量 Skill 运行包

1. 通过 `npx skills add` 分发独立运行包，不预建技术面依赖。
2. 将原标的研究收敛为个股快览，并新增深度个股研究。
3. 用运行包预算和离线 Markdown fixture 验证轻量交付与性能。

每一步都由独立证据与同一个组合级验证入口约束；不引入持久化研究状态、未经单独决策的
数据提供商或交易执行能力。

## v1.0.3（本地实现完成，待验收/发布审批）投研工作台与深度研究升级

1. 保留“深度研究”名称和 `deep-equity-research` 标识，将其升级为可审计、可复算并可形成**仅多头、持仓无关的条件式交易方案**的研究流程；结合独立技术证据给出默认 1–6 个月波段的有效价格区间与注释图。
2. 安装器支持时在安装后询问市场范围；不支持时在首次调用强制多选：美股、港股、A 股、A/H 对比。偏好保存到每台设备的用户可见工作区文件，未设置前不默认美股。
3. 将 Drive 写入重设计为跨设备投研工作台：一个标的/案例一个主文档，记录想法、当前方案、证据/决策变更和复盘；本地生成后必须获得明确确认才写入，支持 revision、冲突显式化和可见 outbox。
4. 改善研究 Markdown 的阅读体验：Markdown 是规范源稿，按需生成 `underwriting.html`；技术证据合格且区间有交集时再生成注释图 `trade-plan.html`。
5. 纳入九章首次承保与财报更新、3 年/8 季度基线、反向 DCF/PVGO 与扩展估值、财报质量 A–D、十六类行业规则包、美股/港股/A 股/AH/VIE/ADR 合同、多数据源适配器和完整离线验收。
6. 新增完全独立的 `investment-analysis`（显示名“投研分析”）skill：只消费明确指定的研究 artifact 或 Drive 文档，默认只做增量讨论卡与方案 revision，不自动搜索、串联或重跑深度研究。

本地实现已完成，待验收与发布审批；版本元数据变更、远端发布和真实 Drive 操作仍须按各自授权门执行。
