# Mars Research Assistant

一个轻量的投研组合 Skill：根入口识别研究意图、只加载需要的能力，把最终文字研究写成可见的
本地 Markdown，并保留来源、`as_of` 与数据缺口。它不读取账户、不下单、不运行后台监控，
也不替用户作交易决定。

## 安装

公开安装入口是 Skills CLI；不提供下载并执行 shell 脚本的安装方式：

```bash
npx skills add archerthegoat/mars-research-assistant \
  --skill mars-research-assistant \
  --agent codex \
  --global \
  --copy
```

安装只复制 `skills/mars-research-assistant/` 这一个运行包，不复制仓库的测试、开发文档或
Git 元数据，也不会预建 Python、uv 或 yfinance 环境。技术面分析是唯一需要第三方 Python
依赖的子 Skill；它在第一次实际请求时检查 uv，并按包内锁文件创建独立 `.venv`。

## 首次使用：市场范围

安装后第一次做单标的研究前，会要求选择研究市场，**可多选**：

```text
请选择你要覆盖的研究市场（可多选）：
[ ] 美股    [ ] 港股    [ ] A 股    [ ] A/H 对比
```

选择保存在活动工作目录的 `mars-market-preferences.json`（按设备保存，只有明确要求时才随
Drive 同步）。未配置前不会默认任何市场；选择 A/H 对比会自动包含港股与 A 股两个基础范围。
明确交易所后缀优先解析；裸代码或纯字母 token（如 `LITE`）一律视为 ticker 候选——组合里
没有以 ticker 拼写命名的模式或档位，匹配不唯一时只要求你选择市场/交易所，不做本地猜测。

## 八个子 Skill

| 任务 | 子 Skill | 交付 |
| --- | --- | --- |
| 决定下一步研究 | Ask Mars | 最小流程、第一步、默认假设和最少输入；不自动研究 |
| 当前市场状态 | 市场快照 | 带来源和时间戳的本地 Markdown 快照 |
| 近期市场事件 | 市场催化剂简报 | 已定事件、发展中风险和传导路径 |
| 快速了解一家公司 | 个股快览（`instrument-research`） | 三项关键公开数据、30 天内 3–5 条公司动态、来源与缺口 |
| 完整基本面与估值 | 深度研究（`deep-equity-research`） | 九章承保报告、财报质量评级、可复算估值与条件式交易方案 |
| 日线结构与关键位 | 技术面分析 | `analysis.md`、`evidence.json` 和临时交互式 HTML |
| 增量讨论既有研究 | 投研分析（`investment-analysis`） | 只基于明确指定输入的讨论卡；不重跑研究、不自动调用其他 Skill |
| 记录交易想法与方案 | Drive 写入 | 先提议、取得独立明确确认后才初始化投研工作台或写入工作台 |

没有明确要求深度时，单标的请求默认走“个股快览”；出现深度研究、估值、财报复盘、投资备忘录、
竞争格局或建模时，才使用“深度研究”（首次承保或财报更新两种模式）。两者都会先核验公司名称、
代码、交易所和发行人；无法唯一对应时要求澄清，不创建可能归属错误的工件。

## 本地交付与边界

最终文字交付默认写到活动工作目录的 `mars-research/`，使用唯一文件名且绝不覆盖旧文件。
PDF 或 PowerPoint 只在用户要求或确实显著改善图表、比较或叙事时额外生成；Skill 安装目录
不是研究输出目录。

个股快览只交付事实：带 `as_of` 的价格、规模/估值锚、最新财务摘要，及最近 30 天的 3–5 条
公司直接相关公告或新闻。它不做估值、技术面、宏观判断或交易建议。

深度研究固定为九章，含财报质量 A–D 评级（C/D 级否决多头入场方案）与可复算估值：三情景
DCF、反向 DCF 与 PVGO 等模型只接收可追溯的 JSON 输入，缺一项即记缺口而非猜测数值；反向
DCF 与 PVGO 用于说明“现价定价了什么”，不构成价值目标。数据齐备且决策门全部通过时，交付
仅多头、持仓无关的条件式交易方案（默认 1–6 个月波段）：入场区间、目标区间、失效条件；
任一决策门不通过时只给观察/等待条件，不输出可执行价位。方案不读取账户、不做空、不输出
仓位比例。

技术面分析另交付同一证据集的临时 Lightweight Charts HTML 与关键位；交易方案把技术图上的
支撑/阻力与价值带结合为可交易价格区间，图上不创造新价位。它不访问实时交易服务或刷新行情。

![技术面分析摘要与交互图表](assets/technical-analysis-showcase.png)

投研分析用于研究完成后的独立后续讨论：只处理你明确指定的本地工件、Drive 文档或
`case_id`，输出新证据、假设变化与论点状态的讨论卡；它与深度研究不自动互相调用。

Drive 写入是可选能力，只记录交易想法与已确定方案（想法日志、当前方案、决策、复盘四区）。
初始化与工作台写入分别需要独立明确确认，互不授权；Drive 不可用时写入可见的本地
outbox 等待手动同步，不后台上传。

## 开发验证

运行时包与开发仓库分离。离线验证不会请求行情、新闻、Google Drive 或账户：

```bash
bash scripts/verify-mars-skills.sh
```

它会验证八个 Skill 合同、运行包不超过 80 个文件/1.5 MiB、快览与深度研究 fixture 各在
1 秒内生成 Markdown，以及技术面既有的确定性验收。真实 yfinance 请求只在发布前的单次
集成验收中运行，不创建定时任务。
